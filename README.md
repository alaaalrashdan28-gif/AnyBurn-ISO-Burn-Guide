## 🧠 Design Philosophy

AnyBurn-2026 was built on three pillars that guide every decision in this repository.

**Clarity over cleverness.** A button should say what it does. A warning should explain the consequence. A success state should feel earned. The interface speaks plainly because optical media already carries enough mystery.

**Respect for the medium.** Discs are physical artifacts with finite lifespans. The software treats each burn as a small act of preservation, offering verification, sensible speed defaults, and honest error reporting rather than silent failure.

**Longevity through documentation.** Code ages; documentation endures. Every feature in this repository is accompanied by prose that will still make sense to a reader five years from now, long after the original author has moved on.

## 🛠️ Troubleshooting Companion

**The drive is not detected.** Confirm the USB or SATA connection, then refresh the device list from the interface. On Windows 11, ensure the optical drive service is running.

**Verification fails repeatedly.** The medium may be defective. Try a different brand or a lower write speed. Logs in the diagnostics folder will reveal whether the failure occurred at the lead-in, data zone, or lead-out.

**Audio tracks sound distorted.** Reduce the rip speed. Some drives struggle with damaged discs at maximum velocity.

**Bootable disc will not start.** Verify that the boot image matches your target firmware mode — UEFI images will not boot on pure BIOS systems and vice versa.

**Interface appears in an unexpected language.** Open the preferences panel and select your preferred locale from the dropdown; the change applies immediately.
